# 参考图二维UI资源

2026-10-18用户明确授权识别所给图片并制成贴图，强调UI质感、圆环仅需二维。最终运行资产采用参考图提取，不使用生成式重画整张界面。

**2026-10-19当前实现**：用户上板反馈偏暗、小字、图标底框及渐变方块。保留参考布局和二维圆环；卡片/文字/图标改用原尺寸原生LVGL绘制。旧`skin_*.c/.png`和低分辨率`ui_plot_background.c`完整保留为历史，当前入口不引用，由链接器剔除，不为移除资源而删除文件。

当前预览背景由`ui_skin.c`的USER2描述符逐行生成：普通292×232、质检278×232，RGB888/1440B共享行缓存。背景不提前量化；所有源经LVGL的19200B RGB888局部缓冲（全宽13行）混合后，才在flush按绝对屏幕坐标统一8×8抖成RGB565，避免按钮/透明边缘未抖色或局部条带重新开始。无整图RAM或全屏缓存，单GUI/软件绘图单元保持。标题和输入数字使用柔和灰色，纯白保留0xFFFF；页面略暖。液晶寄存器不变，不能由电脑像素检查替代面板实测。

## 来源与用途

- `reference_measurement.png`：用户最新普通测量原图（1536×1024），由附件61c58d8b原样复制，避免临时目录清理后无法重建。
- `reference_inspection.png`：用户最新质检原图，同样原样保存（附件865b5697）。
- `skin_header/measurement/inspection/footer/pass/zoom_*.png/.c`：缩至480×320后的卡片、标题、图标、按钮及柔影。主图示例数字、日期、计数、判定/连接状态已移除，实际LVGL单独绘制。
- `metal_ring_192.png`与`ui_metal_ring.c`：从测量原图提取并加孔/外缘透明蒙版的二维示意工件；并非相机实时轮廓。`ui_metal_shadow.c`是轻微柔影，不做实时三维计算。
- `ui_plot_background.c`：146×116背景，按主页面区域放大；网格/标注仍是可开关的原生绘制。
- `skin_button_*`及`skin_settings_icon`保留提取资产；最终页脚已完整含按钮和设置图标，未引用的C资源由链接器丢弃，不占固件Flash。

## 编码与内存

`skin_*.c`使用自定义USER1标记：前512B是256项RGB565调色板，其后每像素一个索引。当前解码器仍兼容旧格式，按一行展开为RGB888，用1440B静态共享缓存，不整图解压。不能直接换成标准I8图片。只支持480×320以内、无旋转/缩放的旧皮肤；单GUI/单软件绘图单元串行访问。

彩色透明工件由同一`metal_ring_192.png`打包为ARGB8888，147456B常驻Flash，保留每色8位精度和透明度，经LVGL小条带变换/混合后再统一转565。柔影为9216B A8，无实时三维运算。旧背景仍为RGB565并由链接器剔除。字体细节及颜色仍受屏幕分辨率/色阶/面板影响；主机截图不代表屏幕实物通过。

## 重建

构建固件只需现有C文件，不需要Python、字体或图片生成服务。更换皮肤时用带Pillow的Python执行：

```text
python tools/extract_ui_skin.py
python tools/build_ui_assets.py
python tools/generate_screen_fonts.py
```

前两份是历史位图重建，当前入口仍仅使用二维工件；第三份为当前官方转换器的屏幕字体重建，工具安装与许可见`../fonts/README.md`。历史`generate_dashboard_fonts.py`用于旧皮肤复现，会覆盖16/26px字体，当前字体以`generate_screen_fonts.py`为准。不要把示例数字烘焙到背景。
